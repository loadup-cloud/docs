    ConfigCenter

    Overview link

    Unified configuration center with Binder/Binding architecture. Supports Local (YAML, no external deps), Nacos, and Apollo as interchangeable backends. Includes Spring @EnableConfigAutoRefresh for hot reload.

    Module Structure link

    Module Purpose
    loadup-components-configcenter-api SPI interfaces, ConfigCenterBindingManager
    loadup-components-configcenter-binder-local Local file-based config (YAML)
    loadup-components-configcenter-binder-nacos Alibaba Nacos integration
    loadup-components-configcenter-binder-apollo Apollo (Ctrip) integration

    Maven Dependencies link

    <dependency>
    <groupId>io.github.loadup-cloud</groupId>
    <artifactId>loadup-components-configcenter-api</artifactId>
</dependency>
<!-- Choose ONE binder -->
<dependency>
    <groupId>io.github.loadup-cloud</groupId>
    <artifactId>loadup-components-configcenter-binder-local</artifactId>
</dependency>

    Configuration link

    loadup:
  configcenter:
    binder: local             # local | nacos | apollo

    Usage link

    @Autowired
private ConfigCenterBindingManager configManager;

String value = configManager.getString("app.timeout", "30");
