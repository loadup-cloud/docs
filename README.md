## 当前同步工具的范围

`../loadup-framework/doc-sync-agent.py` 当前只发现 Framework reactor。拆仓后，它的全量过时页面扫描仍会将 Modules/Testify
的生成页列为待删除，尚不适用于整个站点的全量写入。处理这一范围问题前，使用明确模块限定的同步，避免删除其他仓库页面：

```bash
# 在 docs 仓库根目录执行；默认只读，--check 检查是否需要更新。
python3 ../loadup-framework/doc-sync-agent.py \
  --module loadup-components/security/loadup-components-oauth-server --check

# 更新同一明确模块；不会构建站点。
python3 ../loadup-framework/doc-sync-agent.py \
  --module loadup-components/security/loadup-components-oauth-server --apply
```

API/core 等子模块分别用 `--module` 指定，可重复传入。此入口不负责独立 Modules/Testify
reactor；独立仓库页面同步需要各自的来源映射。持续自动同步取决于工具对仓库范围与页面所有权的识别。全量 `--check`
报告不同步，不代表其他仓库页面可以删除。
